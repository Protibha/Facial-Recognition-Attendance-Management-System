# Facial-Recognition-Attendance-Management-System

This project automates attendance management using facial recognition technology. It identifies students present in a classroom, logs their attendance, and directly sends a detailed email report to the respective professor.

Features
Facial Recognition: Automatically detects and identifies students' faces.
Attendance Logging: Maintains accurate records of students who are present.
Email Integration: Sends attendance reports to professors via email in real time.
User-Friendly Interface: Easy-to-use system for both students and professors.
